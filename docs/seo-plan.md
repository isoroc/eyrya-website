## 三、等你提供（阻塞项）

### 1. 照片（优先级最高）

| 要求 | 说明 |
|---|---|
| 尺寸 | 1600×900（16:9）或更大；OG 会按 1200×630 裁切，主体留中间 |
| 格式 | WebP 或 JPG，单张 < 200KB |
| 路径 | `public/images/ideas/<文章slug>.webp` |
| 建议内容 | 工厂车间、丝印工序、200/箱 装箱、成品颜色阵列、装柜发货 |

放好后在 `lib/posts.ts` 对应文章加两行：

```ts
image: '/images/ideas/custom-foam-fingers-guide.webp',
imageAlt: 'Silk-screen printing a custom logo onto an 18-inch EVA foam hand',
```

页面会自动显示首图（没有图片时不留空位），`Article` 结构化数据同步更新。

### 2. 社交账号（用于 `sameAs`）

Facebook / Instagram / LinkedIn / YouTube / Alibaba 店铺，任意 2 个即可。
给我 URL，我加进 `Organization` 结构化数据的 `sameAs`。

> 不能编造：`sameAs` 指向不存在的账号会被识别为不一致信号。

### 3. 价格区间（用于 B2B 页面）

`foam finger bulk` 页面目前只能写「按项目报价」。若你能给出真实区间
（例如「5,000 只时每只 $1.20–1.80，含单色丝印」），可显著提升批发询盘转化。

### 4. 认证（如果有）

BSCI / ISO 9001 / REACH / CE 等。有则加进 About 页与 `Organization` 结构化数据。

## 四、监控节奏

**每周（5 分钟）**

1. `效果 → 查询`：有没有出现**非品牌**词（不是 `eyrya` 及其拼错）
2. `效果 → 网页`：曝光集中在哪页
3. `索引编制 → 网页`：`已发现 - 尚未编入索引` 有没有从 15 开始下降

**每月**

1. `站点地图`：状态成功，发现 URL 数 = 15
2. `效果 → 导出` CSV 存档（数据只保留 16 个月）

**不要看**：核心网页指标、移动设备易用性、平均排名小数（样本太小时是噪音）。

## 五、现实预期

| 时间 | 期望 |
|---|---|
| 2–4 周 | 产品页与批发页被抓取；`已发现` 从 15 降到 13–14 |
| 1–3 月 | `foam finger bulk` 出现曝光（点击可能仍为 0） |
| 3–6 月 | 若获得外链，进入该词第 3–5 页 |
| 6 月+ | 外链足够时才可能进前两页 |

**唯一能改变「9.5 天抓 1 页」的东西是外链。** 页面改动只能改变"轮到谁"，
改变不了"多久来一次"。

外链最快路径：Alibaba / Made-in-China / Global Sources 的供应商页放官网地址
——那些平台本身就是 `foam finger bulk` 的搜索结果。
